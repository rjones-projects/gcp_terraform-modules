# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-06-03
### Added
- Initial VPC peering module for bidirectional peering between two networks.
- YAML `spec` list with route import/export controls and optional remote peering creation.
- Implementation aligned with [cloud-foundation-fabric `net-vpc-peering`](https://github.com/GoogleCloudPlatform/cloud-foundation-fabric/tree/master/modules/net-vpc-peering).
